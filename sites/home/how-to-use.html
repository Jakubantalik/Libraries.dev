How to use

Every library ships as a prompt. Copy it, paste it into your coding agent, and make it yours. Three steps, no setup.

  1. 1

    Copy the prompt

    Every library page has a Copy prompt button. One paste gives your agent the whole library.

  2. 2

    Paste it in your agent

    Drop it into Claude Code, Cursor or Codex. The agent installs the package and wires it in, matched to your theme.

  3. 3

    Make it yours

    Open the Studio with Pro for every knob, tune it live and copy the result as props.
