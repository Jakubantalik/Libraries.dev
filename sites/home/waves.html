Distortion waves

A colourful wave that carries one screen into the next. The screen pulls toward the button first, then the wave leaves from where it was touched, leaning that way, and leaves its colour on the edges. Vertical, horizontal and center. SwiftUI.

Tune in Studio
Installation 
// Package.swift, or in Xcode: File › Add Package Dependencies… › paste the URL (Branch: main)
.package(url: "https://github.com/Jakubantalik/Libraries.dev", branch: "main")
// …and in your target's dependencies:
.product(name: "DistortionWavesKit", package: "Libraries.dev")
iOS 17+ / macOS 14+. Build through Xcode: the wave is three Metal shaders, compiled by Xcode's build system, not by SwiftPM alone.
Usage 
import DistortionWavesKit

struct Transfer: View {
    @State private var sent = false
    @State private var button = CGRect.zero

    var body: some View {
        DistortionWave(isRevealed: sent, source: button, style: .vertical) {
            ReviewScreen()
        } revealed: {
            ReceiptScreen()
        }
        .overlay(alignment: .bottom) {
            Button("Confirm") { sent = true }
                .onGeometryChange(for: CGRect.self) { $0.frame(in: .global) } action: { button = $0 }
        }
        .ignoresSafeArea()
    }
}

// Flip isRevealed back to collapse the wave into the source.
// Lean toward the finger: pass focus: (the touch point).
Give both sides an opaque background, and keep them free of UIKit-backed views and materials, which SwiftUI cannot pass through a shader. The same view on both sides works too: the wave then carries the screen into itself while you change it.
Types 
// Up the screen from a button at the bottom (the default):
DistortionWave(isRevealed: sent, source: buttonFrame, style: .vertical) { … } revealed: { … }

// Across the screen from a tall source at the left: an edge, a side tab:
DistortionWave(isRevealed: next, source: edgeFrame, style: .horizontal) { … } revealed: { … }

// A ring out from an avatar or icon, inside a sheet or card. The source is
// held sharp at the ring's centre, so it can morph in place:
var style = DistortionWaveStyle.center
style.cornerRadius = 48   // the sheet's corners, for the colour on its edges
DistortionWave(isRevealed: done, source: avatarFrame, style: style) { Sheet() } revealed: { Sheet() }
Options
  • type .vertical, .horizontal or .center; DistortionWaveStyle(type:) gives each type's tuned defaults.
  • palette .colorful (the default), .green (center's), .ocean, .sunset, .mono, .single(color), or your own DistortionWavePalette.
  • Timing anticipation, travel, easing, returnSpeed, pull, inhale, gatherGlow, gatherDots.
  • Wave amplitude, lensWidth, aberration, swell, blur, blurAhead, blurBehind, lead, tail, strength.
  • Edges cornerRadius, rimWidth, rimUnevenness, rimStrength, rimPulse, hairlineWidth, hairlineOpacity, hairlineWhite, hairlineLinger, hairlineFade, linger, rimFade, rimSoftness.
  • Dots particleCount, particleSize, particleReach, particleFlight, particleGap, particleLife, particleSpread.
  • Touch orientation 0–1: how far the vertical and horizontal waves lean toward focus.
  • scrub Holds the wave at a progress 0–1, for screenshots. onFinish is called once it has left and the edges have cleared. Reduce Motion turns it into a crossfade.

Add Distortion waves from Libraries.dev to my SwiftUI app: a colourful
wave that opens from the view that started it and carries one screen into
another (iOS 17+).

Install (Swift Package Manager, branch main):
.package(url: "https://github.com/Jakubantalik/Libraries.dev", branch: "main")
.product(name: "DistortionWavesKit", package: "Libraries.dev")

Usage:
import DistortionWavesKit

DistortionWave(isRevealed: sent, source: buttonFrame, focus: touch, style: .vertical) {
    ReviewScreen()
} revealed: {
    ReceiptScreen()
}

- isRevealed: flip to send the wave out, flip back to collapse it into the source.
- source: the frame it opens from (the button, edge or avatar), in the wave's own coordinate space.
- focus: where the source was touched; the vertical and horizontal waves lean toward it.
- style: .vertical (up from a button at the bottom), .horizontal (right from a tall source at the left) or .center (a ring from an avatar or icon in a sheet, the source held sharp so it can morph in place). DistortionWaveStyle(type:) gives each type's tuned defaults; set cornerRadius to the corners of the view the wave fills, and palette (.colorful, .green, .ocean, .sunset, .mono, .single(color)).
- Give both sides an opaque background; keep UIKit-backed views and materials out of them.
- Build through Xcode: the shaders are Metal, compiled by Xcode's build system.

Match it to my app: pick the type from where the action starts, measure the source with onGeometryChange, and set cornerRadius to my screen's or sheet's corners.
